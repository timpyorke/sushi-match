# My Restaurant — Asset Design (ไม่ implement)

## Context
หน้า `RestaurantScreen` (`lib/ui/restaurant_screen.dart`) ตอนนี้ใช้ emoji + `CustomPaint` (`_ScenePainter`) วาดร้านแบบแบน ๆ ทั้งหมด:
- ไอคอนร้าน = emoji (🐟🍢⛩️🦀), ของตกแต่ง = emoji (🏮🪑🪧) ซ้ำกันทุกร้านต่างกันแค่ราคา
- ฉากร้านเป็นสี่เหลี่ยม+ผ้าใบริ้ว 4 โทนสี ไม่เข้ากับ `bg.png`/`panel.png` ที่เป็นสไตล์ภาพพิมพ์ไม้ ukiyo-e

เป้าหมาย: ออกแบบชุด asset ที่ทำให้ "ร้านโตขึ้น" รู้สึกคุ้มค่าเมื่อซื้อ และแต่ละร้านมีเอกลักษณ์ตามโซน เอกสารนี้เป็นสเปกสำหรับให้ศิลปิน/AI gen ภาพ ยังไม่แก้โค้ด

## Art direction
- ผสม 2 ภาษาที่มีอยู่แล้ว: **โครง/พื้นหลัง** = ภาพพิมพ์ไม้ (indigo, ส้มแดง vermilion, ครีมกระดาษ, ไม้อุ่น เหมือน `bg.png`, `panel.png`) · **ของตกแต่ง** = kawaii glossy ขอบดำบาง เหมือน sprite ซูชิ (`sprites/sushi/*.png`)
- แสงมาจากบนซ้าย เงาใต้ชิ้นเป็น soft ellipse ใน PNG เอง (ให้ของ "ตั้ง" บนพื้นได้)
- พื้นหลังโปร่งใสสำหรับ decor, ห้ามมีตัวหนังสือในภาพ (ใช้ L10n) ยกเว้นลายป้ายที่เป็นสัญลักษณ์ (ไม่ใช่ข้อความ)

## ชุด asset (25 ไฟล์)

โฟลเดอร์ใหม่: `assets/restaurant/` (ต้องเพิ่มใน `pubspec.yaml` ตอน implement)

### 1. ฉากร้านว่าง — 4 ไฟล์
`assets/restaurant/scene_{tsukiji,osaka,kyoto,hokkaido}.png` · **1024×768** (4:3 ตรงกับ `AspectRatio(4/3)`) · ทึบ ไม่โปร่งใส

ร้านเปล่า ๆ ยังไม่มีโคม/โต๊ะ/ป้าย แต่ต้องมี "จุดว่าง" 3 จุดชัดเจนตาม `_slots` เดิม (lantern ซ้ายกลาง, sign บนกลาง, table ขวาล่าง) ห้ามมีของมาบังจุดนั้น

| ร้าน | ฉาก | โทนสี |
| ---- | ---- | ----- |
| Tsukiji | ท่าเรือตลาดปลา แผงไม้ ผ้าใบริ้วน้ำเงิน-ครีม เรือและ Fuji ไกล ๆ ลังน้ำแข็งด้านหลัง | ฟ้า `#BFE3F0` / น้ำเงิน `#2F5D8C` / ไม้ `#B98A5A` |
| Osaka | ซอยริมทาง ป้ายนีออนวาบ ๆ (ไม่มีข้อความ) แผงทาโกะยากิ ผ้าใบแดง-ครีม ยามพลบค่ำ | ส้ม `#F6C9A0` / แดง `#C0392B` / ไม้ `#9C6B43` |
| Kyoto | ระเบียงเรียวกัง ฉากกั้นโชจิ สวนหินและใบเมเปิลแดงด้านหลัง ผ้าม่านโนเรนเขียว | ม่วงอ่อน `#D9CFEA` / เขียว `#5E7F4F` / ไม้ `#8A6B4A` |
| Hokkaido | กระท่อมไม้ท่ามกลางหิมะ หลังคาหนา ควันปล่องบ้าน ทะเลน้ำแข็งไกล ๆ ปูแขวนตาก | ฟ้าน้ำแข็ง `#D4ECF7` / ฟ้าเข้ม `#1F6F8B` / เทา `#8B8F96` |

> ใช้ palette เดียวกับ `_palettes` ใน `restaurant_screen.dart` เป็นหลัก เพื่อให้การ์ดเดิมกับฉากใหม่ไม่ขัดตา

### 2. ของตกแต่ง — 12 ไฟล์ (3 ชิ้น × 4 ร้าน)
`assets/restaurant/decor_{shop}_{lantern,table,sign}.png` · **512×512** โปร่งใส · แสดงที่ ~84dp (ใหญ่กว่า emoji 52 เดิม) · ช่องว่างขอบ ≥ 8% กัน clip

แต่ละร้านมี **รูปทรงต่างกัน** ไม่ใช่แค่เปลี่ยนสี:

| ร้าน | lantern (โคม) | table (โต๊ะ) | sign (ป้าย) |
| ---- | ------------- | ------------ | ----------- |
| Tsukiji | โคมกระดาษแดงทรงกลม ลายคลื่น | ลังไม้ปลาซ้อนกัน มีน้ำแข็งและปลาตัวเล็ก | ป้ายไม้ ลายปลาแกะสลัก (ไร้ตัวอักษร) |
| Osaka | โคมยาวแดงสลับขาว ห้อยพู่ | เคาน์เตอร์ยืนกินพร้อมกระทะทาโกะยากิ | ป้ายนีออนรูปปลาหมึก/ทาโกะ เรืองแสง |
| Kyoto | โคมกระดาษทรงสี่เหลี่ยมลายซากุระ ขาตั้งไม้ | โต๊ะเตี้ย + เบาะซาบูตง + ชุดชา | ป้ายไม้แนวตั้งแขวนม่านโนเรน ลายใบเมเปิล |
| Hokkaido | โคมน้ำแข็งหรือโคมโลหะมีหิมะเกาะ | โต๊ะไม้หนา ปูหม้อต้มร้อน ๆ มีไอ | ป้ายไม้โอบหิมะ ลายปูแดง |

> `table` ใหญ่สุด (เน้นเต็ม 512), `lantern` สูงเรียว, `sign` กว้าง จึงควรจัดสัดส่วนให้ฐานของแต่ละชิ้นอยู่ที่แนวเดียวกันใน canvas (เพื่อไม่ต้องเขียน offset รายชิ้น)

## จุดวาง (anchor) และข้อควรระวังตอน implement ภายหลัง
- เก็บ `_slots` เดิม (`lantern (-0.62,0.12)`, `sign (0,-0.7)`, `table (0.62,0.72)`) เป็นค่าเริ่ม ปรับได้เมื่อได้ภาพจริง
- `assets/ui/` มี `plank/panel/star/coin` อยู่แล้ว **ใช้ซ้ำ** (ห้ามสร้างใหม่) — ชุดนี้ไม่แตะ
- ฉาก `scene_*.png` จะมาแทน `_ScenePainter` ทั้งก้อน (ลบ painter + `_palettes` ได้)
- ขนาดรวมเป้าหมาย: ฉาก ≤ 250KB/ไฟล์, decor ≤ 100KB/ไฟล์ (PNG optimize/pngquant) → รวม < 2.5MB
- ขนาด 3x พอสำหรับมือถือ; ไม่ต้องทำ 1x/2x แยกเพราะ Flutter scale ลงเอง

- วางบน `panel.png` แล้วอ่านชัดบนมือถือ 360dp
- decor ทั้ง 3 ชิ้นไม่ทับกันเมื่อวางที่ `_slots`
- 4 ร้านเห็นต่างกันได้ทันทีแม้ปิดสี (silhouette ต่างกัน)

- decor ที่ "ยังไม่ซื้อ" ใช้ ghost + ราคา ไม่ต้องทำภาพ locked แยก
