# Navigation icons

Created with the built-in imagegen tool. Style references: assets/ui/shopping.webp and assets/ui/gift.webp. Final assets: assets/ui/level.webp and assets/ui/my_restaurant.webp, 256 x 256 lossless WebP, alpha transparency. Original PNGs are beside this file.

## Final prompts

Level: One square transparent navigation icon for Levels in a sushi match-3 game. Folded parchment adventure map, curved dotted route linking three large round nodes, gold star at final node and small red flag. Chunky polished cartoon style, warm orange red and gold, dark brown outlines, bright highlights, slight three-quarter angle, readable at 48px, centered with padding. No words, numbers, border panel or glow.

My Restaurant: One square transparent navigation icon for My Restaurant. Compact Japanese sushi storefront, red orange curved roof, wooden facade, cream noren, red paper lantern, salmon nigiri pictogram on sign. Match existing polished cartoon style, dark brown outlines, warm colors and highlights. Compact silhouette readable at 48px, slight three-quarter view, centered with padding. No writing, ground scenery, glow or surrounding panel.
