# Sushi Trio — Characters

Oct 6, 2026 · @Thongphitak Sowanna

## Overview

ตัวละครในเกมคือ "ลูกค้า" ที่เป็นคนสั่งออเดอร์ในแต่ละด่าน เป้าหมายของด่านเล่าเป็นคำสั่งอาหารผ่านกล่องคำพูด (`OrderBubble` ใน `lib/ui/customer_order.dart`)

- มี 18 คน: ลูกค้าทั่วไป 6 คน (โผล่ได้ทุกร้าน) และลูกค้าประจำโซน 12 คน (โซนละ 3 คน)
- ตอนนี้โค้ดหมุนลูกค้าตามเลขด่าน (`levelId % 6`) และใช้ emoji แทนภาพตัวละคร การผูกกับโซนและการวาดจริงเป็นงานต่อไป
- Art direction ตาม GDD: kawaii flat 2D ตา 2 จุด แก้มแดง

**อารมณ์ที่ต้องมีทุกคน**

| อารมณ์ | เมื่อไหร่ |
| ------ | --------- |
| Idle   | ระหว่างเล่น หน้ายิ้มเล็ก ๆ |
| Happy  | ทำเป้าหมายครบ ตาโค้ง แก้มแดง |
| Sad    | แพ้ด่าน หน้าตก |

## ตัวอุปสรรค: แมวหัวโจก (Cat Boss)

แมวบนกระดานคืออุปสรรคเดิมของเกม (`Cat` ใน `lib/core/game_engine.dart`, เป้าหมาย `shooCats`) แมวหัวโจกเป็นแมวตัวหัวหน้าที่ยากกว่าแมวทั่วไป ใช้เป็นบอสของด่านที่มีแมว

| หัวข้อ | รายละเอียด |
| ------ | ---------- |
| ชื่อ | แมวหัวโจก / Boss Cat — ชื่อเล่น **โจ๊กเกอร์** (Joker) |
| หน้าตา | แมวดำตัวอ้วนใหญ่ กว่าแมวทั่วไป 1 เท่า หูฉีกข้างหนึ่ง ตาเหลืองเหลี่ยม มีแผลเป็นเป็นรอยกากบาทบนจมูก สวมปลอกคอหนามเงิน ปากคาบก้างปลา |
| บุคลิก | อวดดี ขี้โกง หัวหน้าแก๊งแมวจรจัด ชอบขโมยปลาของลูกค้า แต่กลัวเสียงดังและของที่ระเบิด |
| ติดปาก | "เมี้ยวว! ปลานี่ของข้า!" |
| เสียงตอนโดนไล่ | ฟู่! แล้ววิ่งหนีด้วยท่าสะบัดหาง |

**พฤติกรรมบนกระดาน (ข้อเสนอ ต่อยอดจากกลไกแมวเดิม)**

| เรื่อง | แมวทั่วไป | แมวหัวโจก |
| ------ | --------- | --------- |
| ขนาด | 1 ช่อง | 1 ช่อง (ตัวใหญ่กว่าในภาพ) |
| HP | 1–2 | 3–4 |
| ความเร็ว | เดินและกินชิ้นข้างเคียง 1 ช่องต่อเทิร์น | เหมือนกัน แต่ถ้าไม่โดนไล่ 2 เทิร์นติด จะกินเพิ่มเป็น 2 ชิ้นในเทิร์นถัดไป |
| ชอบกิน | ชิ้นที่ลูกค้าสั่ง | ชิ้นที่ลูกค้าสั่ง และชิ้นพิเศษ (ถ้าอยู่ข้าง ๆ) |
| วิธีไล่ | เคลียร์ชิ้นบนหรือข้างช่องที่แมวอยู่ ลด HP 1 | เหมือนกัน และชิ้นพิเศษ (Wasabi, Knife) ที่โดนตัวลด HP 2 |
| แพ้เมื่อ | HP = 0 แมวหนีออกจากกระดาน | HP = 0 โจ๊กเกอร์หนี และทิ้งเหรียญไว้ให้ |

**ด่านบอส:** ด่านที่ 15 ของแต่ละร้านสามารถมีโจ๊กเกอร์โผล่มาป่วนแทนหรือควบคู่กับลูกค้าบอส เป้าหมายคือ "ไล่แมวหัวโจก" ในแง่ธีม ลูกค้าจะพูดว่า "แมวตัวนั้นมันขโมยปลาฉัน!"

**อารมณ์ที่ต้องมี:** Prowl (เดินย่อง), Eat (กิน), Hit (ตกใจ/ฟู่), Flee (วิ่งหนี)

## งานต่อไป

- วาดตัวละคร (`CustomPainter` แบบเดียวกับ `PiecePainter`) แทน emoji
- ผูกลูกค้ากับโซน แทนการหมุน `levelId % 6`
- เพิ่ม key ชื่อของลูกค้า 12 คนใหม่ใน `lib/ui/l10n.dart` (TH/EN)
- อัปเดต mood ตามผลด่าน (happy / sad)
- แมวหัวโจก: ตัดสินใจกติกาจริง (HP, กินชิ้นพิเศษ) แล้วค่อยแก้ `lib/core/game_engine.dart` และรัน `tool/tune.dart` ใหม่
